# ADR · Локальная тестовая сборка

Взяли HTML и CSS из стартового прототипа, чтобы сохранить компоновку и внешний вид конструктора. Обработчики разделены на конструктор, рабочий сценарий и видеоразбор. Используются модули браузера и Node.js 24 без сторонних зависимостей.

Локальный HTTP-сервер слушает `127.0.0.1`. SQLite сохраняет состояние проекта. Запись состояния увеличивает номер версии. Если другая вкладка успела изменить данные, сервер возвращает конфликт и браузер показывает ошибку. Файлы загружаются в локальную папку под отдельными идентификаторами. Сервер обслуживает диапазоны байтов для перемотки. Ссылка упражнения на новый файл сохраняется после загрузки. Сброшенные и заменённые файлы остаются на диске до реализации политики удаления.

Назначение создаёт снимок плана и отдельные отчёты. Отчёт хранит план и факт раздельно, а упражнение связывает свои подходы, видео и отзыв. Редактирование черновика не меняет назначение. Новый блок с тем же названием создаёт новое назначение. Комментарии и корректировки видны клиенту после сохранения проверки. Черновики разметки и проверки до сохранения живут в открытой вкладке.

Переключатель роли предназначен для одного тестировщика. Сервер слушает только локальный адрес, а роли в этой сборке являются режимами интерфейса. Для реальных клиентов потребуются регистрация, проверка прав на сервере и отдельное хранилище с политикой доступа и удаления. Тестовые видео сгенерированы в Canvas, файлы третьих лиц не встроены.

Актуальная и архивная таблицы импортируются независимо и без дедупликации. В JSON хранятся идентификаторы, полные названия, ссылки, номер строки книги и исходные значения столбцов, включая строку исходного листа при её наличии. В конструкторе по умолчанию открывается актуальная таблица. Архивная доступна через переключатель.
