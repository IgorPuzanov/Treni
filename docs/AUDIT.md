# Аудит исходного HTML и журнал изменений

## Исходный прототип

HTML открыт в Microsoft Edge. Из интерфейса конструктора проверено копирование недели 1 до 5. В Т1 каждой из недель 1–5 оказалось по два упражнения, вложенные объекты раздельны. Назначение ставит общий флаг, но выполнение по-прежнему показывает фиксированное упражнение недели 13. Первоначально отчёт заблокирован как отправленный. После сброса отметка подхода оставляет факт пустым. В каждой строке подхода видны дополнительные подписи плана, на экране выполнения нет своей кнопки «Назад». Библиотека содержит 495 записей.

По исходному коду загрузка скрывала отказ IndexedDB и показывала успех даже при несохранённом файле. Дата рождения сравнивалась с фиксированной датой. Таймер пользовался одним глобальным значением отдыха, независимо от параметров подхода.

## Реализация

1. Сохранены стили и структура конструктора. Добавлены раздельный импорт двух таблиц, выбор клиента, сортировка и вставка карточек, редактор быстрых и индивидуальных параметров.
2. Добавлены сервер, сохранение в SQLite и отдельные назначения. Клиентский отчёт использует план назначенного блока и хранит факт по каждому подходу.
3. Подключена загрузка видео к конкретному упражнению, воспроизведение того же файла в отчёте тренера и сохранение отзыва. Добавлены два самостоятельных входа в демонстрацию.
4. Добавлены стоп-кадр, векторные пометки на Canvas, запись разбора, сравнение файлов и отображение вложений у клиента.
5. Приёмка выполняется браузерным скриптом на чистой временной базе. Проверяются перенос мышью из библиотеки, перестановка с событиями DragEvent и порядок после перезагрузки. Лог и снимки сохранены рядом с проектом.
